# hh_fl: A Flower Heavy Hitters app

## Install dependencies and project

```bash
pip install -e .
```

## Run with the Simulation Engine

In the `hh_fl` directory, use `flwr run` to run a local simulation:

```bash
flwr run .
```

Refer to the [How to Run Simulations](https://flower.ai/docs/framework/how-to-run-simulations.html) guide in the documentation for advice on how to optimize your simulations.

## **Configuration Parameters**  

In the `pyproject.toml` file, the following parameters must be set according to your specific experiment:  

#### **Server App Parameters**  

- `num-server-rounds` – Defines the number of **data streaming windows** or the number of files available per client (if each window corresponds to a file). This implementation assumes that all clients contain the same number of files.  
- `local-epochs` – Set to **1** (indicates the number of local training epochs per round).  
- `main-src` – Path to the **directory** where the dataset folder is located.  
- `data-set-partitioned-src` – Name of the **dataset folder** within the main directory.  

#### **Client App Parameters**  

- `top-n` – Number of elements in the **ranking** generated by the Lossy Counting algorithm.  
- `fading-factor` – **Forgetting factor**, which controls how past data fades over time.  
- `epsilon` – **Epsilon** parameter for the Lossy Counting algorithm, determining the granularity of frequency tracking.  
- `support` – **Support threshold** for detecting heavy hitters.  
- `num-supernodes` – Number of **client nodes** used in the simulation.  

## Updates

The notebook **FederatedLossyCounting.ipynb**, previously available in this repository, is no longer compatible with the latest version of **Flower**. Please use the updated implementation in the **hh_fl** folder, which has been adapted for the new version of Flower.  

Additionally, this repository includes a portion of the dataset that can be used alongside the provided code to run experiments.  

To configure the experiments properly, make sure to set the parameters in the **[tool.flwr.app.config]** section of the `pyproject.toml` file according to your specific experiment setup.
